# Changelog

All notable changes to the Node.js Hello World HTTP server project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2023-11-15

### Added
- HTTP server implementation using Node.js built-in http module
- Single `/hello` endpoint returning "Hello world" text response
- Basic error handling for invalid routes
- Server configuration (port, host) via environment variables
- Documentation for setup and usage
